# Moda 🖤🤍

تطبيق متجر إلكتروني كامل بـ **Flutter** لمتجر أزياء نسائية (أحذية – شنط – نظارات شمسية – إكسسوارات) بتصميم أبيض وأسود فاخر ودعم كامل للغة العربية (RTL).

يعمل على **أندرويد** و **iOS** ويحتوي على واجهتين في نفس التطبيق.

> ⚠️ **قبل الرفع على جوجل بلاي اقرأ قسم "النشر على جوجل بلاي" في آخر الملف — فيه نقطة أساسية عن الباك اند.**

- ✅ قيمة الشحن · حد الشحن المجاني · حد تنبيه المخزون

### كيف تعمل "المنتجات المقترحة" تلقائياً؟

بيشتغل بمستويين:
1. **تعلّم من الطلبات السابقة** — لو ناس اشترت الشنطة دي مع جزمة معينة، هيقترح الجزمة دي لأي حد يفتح الشنطة.
2. **احتياطي ذكي** — لو لسه مفيش طلبات كفاية، بيقترح المنتجات المميزة/المخفّضة من التصنيفات المكمّلة.

لو قفلت "الاختيار التلقائي" هيقترح المنتجات المميزة من التصنيفات المكمّلة بس.

## 1️⃣ تثبيت Flutter SDK على ويندوز

1. حمّل Flutter SDK: https://docs.flutter.dev/get-started/install
2. فك الضغط في `C:\src\flutter` (**مش** في `Program Files`)
3. أضف `C:\src\flutter\bin` للـ **PATH**:
   - زرار ويندوز ← اكتب `environment` ← **Edit the system environment variables**
   - **Environment Variables** ← **Path** ← **Edit** ← **New** ← الصق المسار
4. ثبّت **Android Studio**: https://developer.android.com/studio
5. من **SDK Manager ← SDK Tools** فعّل **Android SDK Command-line Tools**
6. **افتح CMD جديد** ونفّذ:
   ```bash
   flutter doctor
   flutter doctor --android-licenses
   ```

> 💡 أسرع طريقة: ثبّت إضافة **Flutter** في VS Code ← `Ctrl+Shift+P` ← `Flutter: New Project` ← **Download SDK** (بيضبط الـ PATH لوحده).

## 🔌 تفعيل الخدمات الخارجية

### 💳 الدفع بالفيزا (Paymob)

التطبيق حالياً بيستخدم **بوابة تجريبية** شغالة بالكامل. للتفعيل الحقيقي:

1. اعمل حساب تاجر: https://paymob.com
2. من لوحة التحكم خد: **API Key** · **Integration ID** · **iframe ID**
3. حطهم في `lib/core/config/api_config.dart`:
   ```dart
   static const String paymobApiKey = 'ضع_المفتاح_هنا';
   static const String paymobIntegrationId = '...';
   static const String paymobIframeId = '...';
   ```
4. اعمل `PaymobGateway implements PaymentGateway` في `payment_gateway.dart` (الخطوات الأربعة مشروحة في التعليقات داخل الملف)
5. بدّل `MockPaymentGateway()` بـ `PaymobGateway()` في `card_payment_screen.dart`

**الشاشات وتدفق الدفع كله جاهز — مش هتغيّر أي واجهة.**

### 🔐 تسجيل الدخول بجوجل

التطبيق بيستخدم **حساب تجريبي** حالياً. للتفعيل الحقيقي:

1. أضف الحزمة في `pubspec.yaml`: `google_sign_in: ^6.2.1`
2. اعمل مشروع على https://console.firebase.google.com
3. حمّل `google-services.json` وحطه في `android/app/`
4. سجّل بصمة SHA-1: `cd android && ./gradlew signingReport`
5. حط الـ Client ID في `ApiConfig.googleWebClientId`
6. فعّل الكود الجاهز في `auth_repository.dart` (مكتوب بالكامل داخل التعليقات)

### 🔔 إشعارات نظام التشغيل

الإشعارات الحالية **داخل التطبيق** (تبويب الإشعارات مع عدّاد) وشغالة تماماً. لإشعارات تظهر والتطبيق مقفول:

1. أضف: `flutter_local_notifications` (تنبيهات محلية) و/أو `firebase_messaging` (إشعارات من السيرفر)
2. `NotificationsProvider.push()` هو المكان الوحيد اللي هتضيف فيه استدعاء الحزمة

## 🔄 الربط بالباك اند (ASP.NET Core)

التطبيق بيشتغل ببيانات تجريبية بنفس واجهات الـ Repository النهائية:

1. غيّر `baseUrl` في `lib/core/config/api_config.dart`
2. اعمل تنفيذ جديد لكل Repository:
   ```dart
   class ApiProductRepository implements ProductRepository { ... }
   ```
3. بدّل `MockProductRepository()` بـ `ApiProductRepository()` في الـ Provider — **بدون تغيير أي شاشة**

الواجهات الجاهزة: `AuthRepository` · `ProductRepository` · `CategoryRepository` · `OrderRepository` · `PaymentGateway`

> البيانات التجريبية بترجع لوضعها الأصلي عند إعادة التشغيل. المحفوظ محلياً: السلة · الجلسة · الحسابات · المفضلة · الإشعارات · الإعدادات · التقييمات.

# 🚀 النشر على جوجل بلاي

## 🔴 اقرأ ده الأول — أهم نقطة في الملف كله

التطبيق حالياً بيحفظ البيانات **على الجهاز نفسه** (تخزين محلي). ده معناه:

> المنتجات اللي بتضيفها من موبايلك **مش هتظهر** لعميل تاني على موبايله.
> كل واحد نزّل التطبيق هيبقى عنده نسخة منفصلة فاضية.

ده كويس جداً **للعرض والتجربة**، لكن **مش كافي لمتجر حقيقي على جوجل بلاي**.

### يعني إيه؟ عندك مسارين

| المسار | يصلح لإيه | المطلوب |
|---|---|---|
| **١. ارفعه كده** | عرض للعميل · نسخة تجريبية · تطبيق كتالوج على جهاز واحد | جاهز دلوقتي |
| **٢. اربطه بسيرفر** | متجر حقيقي كل العملاء يشوفوا نفس المنتجات والطلبات توصلك | باك اند (ASP.NET Core اللي عندك) + استضافة |

**للمسار التاني:** التطبيق مبني عشان ده بالظبط — غيّر `baseUrl` في `api_config.dart` واعمل `ApiProductRepository` بدل `MockProductRepository` (راجع قسم "الربط بالباك اند" فوق). **مش هتغيّر ولا شاشة واحدة.**

## الخطوات بالترتيب

### 1️⃣ صفّر البيانات التجريبية

**من داخل التطبيق:** لوحة التحكم ← الإعدادات ← **مسح البيانات التجريبية** ← **تصفير التطبيق بالكامل**

**وفي الكود:** افتح `lib/core/config/app_config.dart` وغيّر:
```dart
static const bool useDemoData = false;
```

### 2️⃣ اعمل مفتاح التوقيع (Keystore)

مرة واحدة بس في حياتك — **واحتفظ بيه في مكان آمن، لو ضاع مش هتقدر تحدّث التطبيق أبداً.**

```powershell
keytool -genkey -v -keystore C:\Users\emymo\upload-keystore.jks -storetype JKS -keyalg RSA -keysize 2048 -validity 10000 -alias upload
```
> لو `keytool` مش معروف، استخدم المسار الكامل:
> `"C:\Program Files\Android\Android Studio\jbr\bin\keytool.exe"`

هيسألك كلمة سر واسمك وبلدك — جاوب واحفظ كلمة السر.

### 3️⃣ اعمل ملف `android/key.properties`

ملف جديد في مجلد `android` باسم `key.properties`:
```properties
storePassword=كلمة_السر_اللي_كتبتها
keyPassword=نفس_كلمة_السر
keyAlias=upload
storeFile=C:/Users/emymo/upload-keystore.jks
```
> استخدم `/` مش `\` في المسار. الملف ده متضاف لـ `.gitignore` تلقائياً.

### 4️⃣ ابنِ ملف الرفع (AAB)

جوجل بلاي بيطلب **App Bundle** مش APK:

```powershell
flutter clean
flutter build appbundle --release
```

الملف هيطلع في:
```
build\app\outputs\bundle\release\app-release.aab
```

### 5️⃣ اعمل حساب مطوّر

1. ادخل: https://play.google.com/console
2. سجّل بحساب جوجل ← **$25 مرة واحدة مدى الحياة**
3. جوجل هيطلب تأكيد الهوية (بطاقة/جواز) — بياخد من يوم لأسبوع

### 6️⃣ جهّز مواد المتجر (قبل ما تبدأ)

| المطلوب | المواصفات |
|---|---|
| **أيقونة التطبيق** | PNG مربعة **512×512** |
| **صورة الغلاف** | **1024×500** |
| **لقطات شاشة** | من **2 لـ 8** صور — أقل عرض 320px (صوّر من الموبايل) |
| **وصف قصير** | 80 حرف كحد أقصى |
| **وصف كامل** | 4000 حرف كحد أقصى |
| **سياسة الخصوصية** | **رابط إلزامي** — اعملها مجاناً من https://app-privacy-policy-generator.firebaseapp.com وارفعها على أي استضافة أو GitHub Pages |

### 7️⃣ أنشئ التطبيق وارفعه

1. **Create app** ← اسم `Moda` ← عربي ← مجاني
2. املا **Store listing** (الوصف والصور)
3. **Content rating** — استبيان قصير عن محتوى التطبيق
4. **Data safety** — قل إيه البيانات اللي بتجمعها (الاسم، الهاتف، العنوان للتوصيل)
5. **Target audience** — 18+ للتطبيقات التجارية
6. **Production ← Create new release ← Upload** ← ارفع ملف `app-release.aab`
7. **Send for review**

في `pubspec.yaml` زوّد الرقم:
